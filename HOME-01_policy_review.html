5) 추천글 정책

  • 대상: 최근 3개월 게시글
  • 점수식: likes*10 + comments*3 + views*1
  • 후보군: 상위 20~30개
  • 노출: 후보군에서 랜덤 5개
  • 조회수 정책: 3초 체류 + 24시간 중복 제외 시 +1
  • 홈 카드에는 조회수 미노출(백엔드 집계 전용)
Assumption: 개인 학습 목적상 “세션 내 랜덤 시드 고정” 정책을 채택한다.

9) API 계약 (학습용 초안)

GET /v1/home

  • 목적: 홈 전체 섹션 데이터 반환
  • query: region?, disease_code?
  • response: hero, doctor_section, community_section, health_section, policy_flags

POST /v1/community/posts/{postId}/view-events

  • body: view_duration_ms, session_id, device_id
  • 규칙: 3000ms 미만 discard, 24h dedupe

POST /v1/community/posts/{postId}/likes/toggle

  • auth: Member required
  • idempotency key 권장
  • response: liked(boolean), like_count(number)
