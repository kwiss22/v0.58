## 6. 예외 케이스 정리

### EX-01 · 데이터 없음 — 커뮤니티 게시글이 하나도 없는 경우
- **현재 동작:** `getRandomCommunityPost()` 반환 타입이 `CommunityPost`(null 불가)로 선언되어 있음. `COMMUNITY_POSTS` 배열이 비어있으면 `COMMUNITY_POSTS[0]` → `undefined` 반환 (런타임 타입 불일치). `randomPost` 상태에 `undefined`가 세팅됨 → `{randomPost && ...}` 조건이 falsy → 카드 미표시. 현재는 목 데이터(하드코딩)라 실제로 빈 배열이 되는 경우 없음.
- **처리 여부:** ❌ 미처리
- **논의 필요:** `getRandomCommunityPost()` 반환 타입을 `CommunityPost | null`로 수정하고, 배열 empty 체크(`length === 0`) 추가 필요. API 연동 후 응답이 빈 배열일 때 카드 미표시 + 우측 명의병원 카드 full-width 처리 정책 확인 필요.

---

### EX-02 · 데이터 없음 — 선택 질환 탭에 해당하는 의사가 0명인 경우
- **현재 동작:** 의사 리스트 영역이 빈 상태로 렌더링 (빈 화면 처리 없음)
- **처리 여부:** ❌ 미처리
- **논의 필요:** "해당 질환의 명의 정보를 준비 중입니다" 등 Empty State UI 추가 필요.

---

### EX-03 · 위치/권한 — 위치 권한 거부 또는 위치 조회 실패
- **현재 동작:** Google Maps가 하드코딩된 서울 중심 좌표로 표시됨
- **처리 여부:** ⚠️ 부분 처리
- **논의 필요:** 위치 기반임을 명시한 카드 문구와 실제 동작 불일치. 위치 권한 요청 여부 정책 결정 필요.

---

### EX-04 · 네트워크 — 오프라인 또는 네트워크 오류 상태
- **현재 동작:** Google Maps `iframe` 로드 실패 → 빈 회색 박스 / 건강 기사 URL 오픈 실패
- **처리 여부:** ❌ 미처리
- **논의 필요:** 오프라인 감지 후 안내 토스트 또는 Fallback UI 필요.

---

### EX-05 · 데이터 소스 — 건강 정보 기사 12개 모두 소진 후 추가 요청
- **현재 동작:** "모든 건강 정보를 확인했습니다" 문구 노출 후 로딩 중단
- **처리 여부:** ✅ 처리됨
- **논의 필요:** 현재 로컬 상수 데이터. API 연동 시 pagination/cursor 방식으로 교체 필요.

---

### EX-06 · 이미지 — 의사 프로필 이미지 없음
- **현재 동작:** User 아이콘 플레이스홀더 표시
- **처리 여부:** ✅ 처리됨
- **논의 필요:** 실제 이미지 URL 연동 시 `ImageWithFallback` 컴포넌트 사용 권장.

---

### EX-07 · 이미지 — 건강 정보 기사 썸네일 없음
- **현재 동작:** 회색 박스 플레이스홀더 (`w-20 h-20 bg-gray-200`)
- **처리 여부:** ⚠️ 부분 처리
- **논의 필요:** 실제 기사 썸네일 URL 연동 필요. OG image 크롤링 또는 기사별 이미지 매핑 방법 협의 필요.

---

### EX-08 · 외부 링크 — 건강 기사 외부 URL iframe 차단 (X-Frame-Options)
- **현재 동작:** `iframe` 내 빈 화면 또는 오류 표시
- **처리 여부:** ❌ 미처리
- **논의 필요:** kormedi.com 등 외부 사이트의 `iframe` 허용 여부 확인 필요. 차단 시 외부 브라우저(`_blank`) 오픈으로 전환 검토.

---

### EX-09 · 접근성 — 전화하기 버튼 (`tel:`) — 웹 브라우저 환경
- **현재 동작:** 웹에서 `tel:` 링크 클릭 시 OS에 따라 동작 상이
- **처리 여부:** ⚠️ 부분 처리
- **논의 필요:** 네이티브 앱(React Native / WebView) 환경에서만 정상 동작 확인 필요.

---

### EX-10 · 스크롤 — body scroll과 내부 컨테이너 scroll 충돌
- **현재 동작:** `scrollContainerRef`(`flex-1 overflow-y-auto`)로 내부 스크롤 처리
- **처리 여부:** ✅ 처리됨
- **논의 필요:** 모달 오픈 시 `document.body.style.overflow = hidden` 처리 — 일부 iOS Safari에서 미동작 사례 확인 필요.
