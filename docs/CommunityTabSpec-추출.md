# 커뮤니티 탭 화면정의서 (UI/UX)

- **소스:** `src/app/components/docs/CommunityTabSpec.tsx`
- **버전:** v0.6 · UI/UX 중심
- **참고:** 프로토타입 화면·더미 데이터와 구분

---

## 문서 범위

본 문서는 **UI/UX·정책·인터랙션**을 정의합니다. 데모 화면의 게시글·숫자·댓글 등은 **더미**이며 실제 서비스 데이터와 동일하지 않습니다. API·신고 처리·저장소 등은 실서비스 설계에 맞게 별도 확정합니다.

## 개요

커뮤니티는 환자들이 **병원·의사 방문 후기**, **치료 경험**, **궁금한 점**을 공유하는 공간입니다.

### 핵심 가치

- **신뢰도:** 병원진료인증 배지로 실제 경험 후기 구분
- **전문성:** 의사 인증 배지로 의료진 조언 표시
- **안전성:** 신고 기능으로 부적절한 콘텐츠 차단

---

## 1. 헤더

- **커뮤니티 페이지 상단 바:** 좌측에 「커뮤니티」 제목만 (이 줄 안에는 돋보기 없음)
- **통합 검색:** 반응형 웹 전역 레이아웃에서 홈·명의 찾기·커뮤니티일 때 **메인 뷰 우상단 고정** 돋보기(본문 스크롤과 무관). 커뮤니티 페이지 헤더 내부가 아님.

---

## 2. 카테고리 필터

- **표시 조건:** 전역 검색 중이거나 특정 유저 필터 중일 때 자동 숨김 (AnimatePresence)
- **1차 필터 탭:** `searchFilter` · `userFilter` 없을 때 표시. 검색/유저 필터 활성 시 1·2차 전체 숨김.
  - 질병별 / 진료과별
- **2차 칩 (질병별):** 전체, 인기 질환 칩, 「질환 검색」
- **2차 칩 (진료과별):** 전체, 내과, 외과, 소아과, 피부과 등

### 질환 검색 버튼 동작

- 클릭 시 칩 행이 **질환명 검색 입력창**으로 교체 (슬라이드 애니메이션)
- 좌측 ← 버튼: 검색 모드 종료 → 칩 행 복귀
- 플레이스홀더: `질환명 검색...`
- 실시간 필터링: DISEASE_LIST 전체에서 검색어 포함 항목만 표시
- 인기 질환 칩에 없는 질환 선택 시: 해당 질환명 칩이 X 버튼과 함께 표시

### 검색 결과 표시 규칙 (카테고리 필터 내부)

- **입력 전:** 결과 칩 영역 미표시 (검색창만)
- **결과 있음:** 부분 일치 질환명 최대 **10개** 칩 (카테고리 소스: 내부 질환 DB·질환 그룹 분류 기준)
- **결과 없음:** `검색 결과가 없습니다. 다른 질환명을 검색해 보세요.`
- **결과 선택:** 질환 칩 탭 시 필터 적용 → 검색 모드 종료 → 검색어 초기화
- **필터 효과:** 선택 질환과 정확히 일치하는 게시글만 목록에 남음, 총 건수 즉시 갱신

### 필터 결과 상태 정의 (피드 영역)

**공통**

- **결과 0개:** 빈 상태 카드 (아이콘 + `아직 [선택 카테고리] 후기가 없어요` + 안내 문구)
- **결과 1개 이상:** 게시글 카드 목록, 상단 **총 n건** 실시간 반영
- **결과가 많을 때:** 페이지네이션 없이 같은 목록 영역에서 연속 표시, 스크롤로 탐색
- **정렬 유지:** 최신순/인기순 상태를 필터 결과에 재적용
- **고정/스크롤 분리:** 카테고리 필터, 정렬 헤더, 우상단 통합검색 진입점은 유지, **게시글 목록 영역만** 스크롤

**회원** (앱에서 회원 역할일 때 TSX에만 표시되는 항목)

- 결과 0개 안내: `첫 후기를 남겨보세요!`
- 임시저장 배너(조건부), 우하단 글쓰기 버튼 노출

**비회원** (게스트 역할일 때)

- 결과 0개 안내: `다른 카테고리를 선택해 보세요.`
- 비회원 사용량 배너(조건부), 우하단 글쓰기 버튼 미노출

### 커뮤니티 내 검색 vs 통합 검색

- **카테고리 필터 내 「질환 검색」:** 질환명으로 게시글 필터링 (커뮤니티 전용)
- **통합 검색 모달:** 우상단 돋보기 → 명의/병원/커뮤니티 탭. **「커뮤니티에서 더 보기」**는 **커뮤니티 탭으로만 전환**, 검색어는 커뮤니티 필터로 넘기지 않음

## 3. 헤더 하단 배너 영역

최대 3종:

1. **면책 고지 배너** — 항상 표시  
   `이 커뮤니티의 내용은 의료 전문가의 조언을 대체하지 않습니다.`
2. **비회원 사용량 배너** — 비회원 + 조회 횟수 소진/경고 시 (무료 이용 한도 안내 배너·프로토타입 화면 참조)
3. **임시저장 이어쓰기 배너** — 로그인 사용자 + 이 기기에 초안 존재 시  
   - 「이어서 쓰기」→ 글쓰기 화면  
   - 반투명 배경 + 가운데 확인 카드 (타이틀 「AIGA」, 불러올지 문구, 저장 시각·제목 미리보기, 취소(삭제) / 불러오기)

---

## 4. 피드 목록 헤더 (총 건수 + 정렬)

- **위치:** 피드 카드 목록 바로 위
- **정렬:** 최신순 / 인기순만 (댓글많은순 없음)
- **인기순:** likeCount + comments 합산 내림차순
- **활성 탭:** 진한 회색, 비활성: 연한 회색
- **총 건수:** 현재 필터/검색 조건 적용 후 실시간

---

## 5. 유저 필터 배너 (조건부)

- 프로필 팝업에서 「이 사용자 글만 보기」 시 표시
- X 버튼: 필터 해제
- 유저 필터 활성 시 카테고리 필터 자동 숨김

---

## 6. 게시글 카드 (목록)

- **프로필 아이콘:** 클릭 시 UserProfileModal
- **작성자명:** 가입 시 또는 **My 페이지 닉네임** 기준
- **작성 시간:** 상대 시간 형식
- **(수정됨):** 수정 시 표시, 호버 시 수정 일시 툴팁
- **제목 + 인증 배지:** 병원진료인증(`isVerified=true`) 시 VerificationBadge
- **질환 태그:** disease 있으면 보라 칩
- **본문 미리보기:** 최대 2줄, 전문은 PostDetailModal
- **첨부 이미지:** 1장 h-48, 2장 그리드 h-32, 3장 h-24, 4장 이상은 3장까지 + `+N` 딤 오버레이; 카드 탭은 상세로
- **통계:** 공감해요 + 댓글 수 (**조회수 없음**)

## 배지 시스템

### 병원진료인증

- 실제 해당 병원 방문 환자 후기
- 영수증/처방전 등 제출 → OCR 자동 인식 검증 후 승인
- 제목 옆 VerificationBadge, 파란 톤 + 방패 + 「인증」

### 의사 인증

- **의미:** 의사 면허번호로 본인 인증을 완료한 의료진
- **인증 방법:** 의사 면허번호 입력 + OCR 자동 인식 검증 후 승인 (향후 기능)
- 게시글·댓글·리뷰 표시, 리뷰 1개 제한 등
- 초록 톤 + 체크 + 「의사 인증」

## 사용자 인터랙션

**비회원 제한:** LoginRequiredToast (중앙 모달, 카카오/네이버 등 — 공통 탭)

### 공감해요

- 비회원: 비활성 + 클릭 시 LoginRequiredToast (`feature: "공감"`)
- 회원: 토글, 숫자 ±1

### 댓글

- 비회원: 입력 비활성, 플레이스홀더 로그인 유도, 클릭 시 모달
- 회원: 입력 활성, 등록 즉시 반영
- **댓글 작성자:** 닉네임(`comment.userName`), 의사 인증 시 배지

### 댓글 좋아요 / 답글

- 비회원: LoginRequiredToast
- 회원: 하트 토글(빨강), 답글 입력창
- **답글 UI:** 들여쓰기로 계층 표시, **별도 @멘션 없음**

## 신고 기능

- **회원(타인):** 신고 → ReportModal
- **본인:** 신고 항목 없음
- **비회원:** ⋮ 메뉴는 있으나 신고는 `!isGuest`로 숨김 (공유는 표시)

신고 사유: 게시글 7종, 댓글 6종 (세부는 TSX 5절 참고). 접수 토스트 후 처리 결과 무통보 정책(A안) 등 동일.

## 9. WritePostModal (회원)

- **진입:** 우하단 +, 게시글 수정
- **파일:** `WritePostModal.tsx`
- **구성 요약:** 헤더(타이틀·자동저장·X), 질환명*, 제목*(최대 50자), 내용*(민감정보 경고·통합 입력·사진 최대 10장 JPG/PNG/WEBP·압축), 병원진료인증(신규), 푸터 취소/게시·수정 완료
- **유효성:** 제목·본문·질환·진료과 필수

## 10. 임시저장 (이 기기)

- 새 글 / 수정별 초안 분리
- 글·사진·순서 복원 가능
- **트리거:** 입력 멈춤 약 **3초** 후 자동 저장; **X 닫기**는 내용 있으면 저장 후 닫기; **푸터 취소**는 저장 없이 닫기
- 재진입 시 복원 다이얼로그 (AIGA 타이틀, 취소(삭제)/불러오기)
- 게시 완료·취소(삭제) 시 초안 삭제
