# 1. 팝업 UI (모달)

## 1-1. 의사 프로필 상세 팝업

**재사용:** 홈·명의찾기·커뮤니티에서 의사 카드 터치

| 진입 |
|------|
| 홈 — 「주요 질환 인기 명의」 카드 터치 |
| 명의찾기 — 검색 결과 의사 카드 터치 |
| 커뮤니티 — 게시글에 태그된 의사 이름 터치 |

**제공 정보:** 프로필(이름·병원·진료과·전문분야), 경력, 학력, 논문(1~3편 항상 / 4편↑ 아코디언)

| 기능 | 회원 | 비회원 | 설명 |
|------|:----:|:------:|------|
| 의사 정보 보기 | ✅ | ✅ | |
| AI 소셜리뷰 | ✅ | ✅ | |
| 다른 환자 리뷰 | ✅ | ✅ | |
| 리뷰쓰기 | ✅ | ❌ | 비활성+Lock, 클릭 시 로그인 필요 |
| 즐겨찾기 | ✅ | ❌ | 동일 |

**비회원:** 리뷰쓰기·즐겨찾기 클릭 → **LoginRequiredToast** (중앙 카드 모달, 딤 — 이름과 달리 하단 토스트 아님)

**특수:** 프로필 사진 없음 → 기본 아이콘; 리뷰 없음 → 「첫 리뷰를 작성해보세요」

**AIGA 리뷰 카드 이미지:** 커뮤니티 목록과 동일 — 1장 h-48 전폭, 2장 h-32, 3장↑ h-24 + 3번째에 `+N` (`bg-black/50`); 클릭 시 ImageLightbox (이전/다음, N/전체, 썸네일, ESC 등)

## 1-2. 커뮤니티 게시글 상세 팝업

**모듈:** CommunityPostModal(홈·통검) / PostDetailModal(커뮤니티 피드) — UX 패턴 동일 목표

| 진입 |
|------|
| 홈 추천글 카드 → CommunityPostModal |
| 통합 검색 커뮤니티 결과 → CommunityPostModal (검색어 변경 시 세션 내 공감 오버라이드 초기화) |
| 커뮤니티 피드 → PostDetailModal |

**제공:** 제목·전문 본문, 작성자, 태그, 일시, 좋아요·댓글 수, 댓글·대댓글

| 기능 | 회원 | 비회원 | 설명 |
|------|:----:|:------:|------|
| 게시글 읽기 | ✅ | ✅ | |
| 공감 | ✅ 토글 | ❌ LoginRequiredToast | 화면별 state, 탭 간 자동 동기 없을 수 있음 |
| 댓글 읽기 | ✅ | ✅ | |
| 댓글 작성 | ✅ | ❌ | 비활성+로그인 안내 |
| 커뮤니티 탭 이동 | ✅ | ✅ | 「커뮤니티에서 더 보기」 등 |

**특수:** 댓글 없음 → 「첫 댓글…」 (⚠️ 미구현 표기 있음); 긴 글 → 스크롤

> **Note:** 조회수(views) 제거 — 카드·상세 모두 미표시.

### PostDetailModal 화면 구성 (요약)

- 헤더: 좌 「게시글」+ ⋮ + 우 X (뒤로가기 없음)
- 작성자: 프로필 + 닉네임 등 (표시 전용 — 상세/댓글/대댓글 작성자 프로필 클릭 → 작성자 프로필 창 연결은 추후 일괄 적용, 이번 범위 제외. 현재는 목록 피드 카드의 프로필 클릭만 연결)
- 본문: 제목·전문·태그·이미지(탭 → ImageLightbox)
- 액션 바: **공감 + 댓글 수만** (AI상담·명의찾기 버튼 없음)
- 병원/의사 미니카드: 데이터 있을 때 조건부
- 댓글 영역 + 입력

### ⋮ 더보기 메뉴

- **공유하기** 최상단 — 비회원 포함 항상
- 작성자 본인(회원): 공유 / 수정 / 삭제 (신고 없음)
- 타인(회원): 공유 / 신고
- 비회원: 공유만 (신고 `!isGuest`)

**댓글 ⋮:** 본인 수정·삭제 / 타인(회원) 신고 / 비회원 접근 불가

### 첨부 이미지

- 작성 시: 최대 10장, JPG·PNG·WEBP, 장당 5MB, `N/10`
- 상세 본문: `flex-wrap gap-2`, 전부 표시, +N 없음, 탭 → ImageLightbox

## 1-3. 리뷰 작성 팝업

의사 프로필 위 중첩. **필수:** 별점(1~5), 리뷰 본문 최소 50자 (최대 무제한). **선택:** 사진 최대 10장 동일 제한.

- 저장하기: 조건 충족 시만 활성; 취소 버튼 없음, X로 닫기
- 이미지는 **임시저장에 미포함** (텍스트·별점만 복원)
- 임시저장 키: `aiga_review_draft_{doctorId}`, 3초 debounce 자동저장, X 시 즉시저장, 복원 다이얼로그, 이어쓰기 배너(회원) 등 — TSX와 동일 정책

# 3. 데이터 상태 UI

전역 패턴 — 구역별로 로딩/에러/표시 혼재 가능.

## 3-1. 로딩

언제: API 대기, 진입, 새로고침, 필터/정렬 변경  
표시: 파란 스피너 + 「불러오는 중...」  
예: 홈 건강정보·인기명의·커뮤니티 추천글 구역 등

> 0.5초 이하 깜빡임 방지 미표시 가능 — 정책 검토

## 3-2. 에러

서버/네트워크/500 등 → 아이콘 + 메시지 + 「다시 시도」  
미확정: 메시지 상세도, 재시도 횟수, 고객센터 링크

## 3-3. 데이터 없음 (Empty)

| 상황 | 제목 | 부가 |
|------|------|------|
| 검색 결과 없음 | 검색 결과가 없습니다 | 다른 검색어… |
| 필터 결과 없음 | 조건에 맞는 항목이 없습니다 | 필터 변경… |
| 리뷰 없음 | 아직 작성된 리뷰가 없습니다 | 첫 리뷰… |
| 게시글 없음 | 아직 작성된 게시글이 없습니다 | 첫 게시글… |
