## 1-2. 커뮤니티 게시글 상세 팝업

**재사용:** 홈·커뮤니티에서 게시글 카드 클릭

| 진입 |
|------|
| 홈 — 「커뮤니티 추천글」 카드 |
| 커뮤니티 — 목록 아무 글 |

**제공:** 제목·본문, 작성자, 태그, 일시, 좋아요·댓글, 댓글·대댓글

| 기능 | 회원 | 비회원 | 설명 |
|------|:----:|:------:|------|
| 게시 읽기 | ✅ | ✅ | (TSX 표기: 「게시 읽기」) |
| 댓글 읽기 | ✅ | ✅ | |
| 댓글 작성 | ✅ | ❌ | 로그인 필요 |
| 커뮤니티 탭 이동 | ✅ | ✅ | 「커뮤니티에서 더 보기」 |

**특수:** 댓글 없음 ⚠️ 미구현; 비회원 댓글 입력창 ✅; 긴 글 스크롤 ✅

**첨부 이미지:** 업로드 10장·형식·용량 동일; 상세 본문 flex-wrap 전체 표시 + ImageLightbox; 목록 카드 vs 상세 정책 차이 표 동일

> **BizNote:** v0.6 기준 조회수 제거 — 카드·상세 미표시.

*(비회원 정의서에만 있는 내용: 게시글 공감 행, CommunityPostModal/PostDetailModal 경로 구분, ⋮ 메뉴 3열 권한, 댓글 ⋮ 패턴 전체 문단 등)*

## 1-4. 통합 검색 모달 (GlobalSearchModal)
