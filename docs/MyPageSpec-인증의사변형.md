> 본 문서는 **인증 완료(`verificationStatus: 'verified'`)** 상태의 변형만 다룹니다.

| 영역 | 일반 회원 (현재) | **인증 의사 (변경)** |
|------|----------------|---------------------|
| 아바타 | 사람 아이콘 + 그라데이션 | **실명 이니셜 + 파란 그라데이션** (예: 「구」) |

## 1. 진입 조건 — F-MY-110

### 1-1. 노출 조건

- 사용자가 **로그인 상태**이고 `verificationStatus === 'verified'`일 때 마이페이지에 진입.
- 비로그인 / 일반 회원 / 검토중 / 거절·만료는 **이 변형이 적용되지 않음** (기존 정의서대로).

### 1-2. 데모/스펙 패널 토글

기존 «비회원 / 회원» 토글 옆에 **«인증 의사»** 항목을 추가합니다.

```
[ 비회원 ] [ 회원 ] [ 인증 의사 ]
```

→ 노션·데모용 토글이며, 실서비스에서는 서버 응답으로 결정됩니다.

### 1-3. 정상 흐름

1. GNB의 **MY** 탭 진입.
2. 상단 앱바: 「마이페이지」 + 우측에 작은 **«의사» 뱃지** (이미지 2의 헤더 우측 캡슐).
3. 하단으로 스크롤하면 M01~M05 변형 블록이 노출됩니다.

### 1-4. 예외

- 인증이 만료(`expired`)되면 변형 적용 중단 → 일반 회원 정의서로 돌아감 + 상단에 «인증이 만료되었습니다. 재인증하시겠어요?» 배너 노출.
- 인증이 거절(`rejected`)되면 변형 미적용 + 마이페이지에 «인증 거절» 안내 카드(사유 + 재신청 버튼).

## 2. M01 — 프로필 요약 (변경)

### 2-1. 좌측 아바타

- 디자인: 원형, **`bg-gradient-to-br from-blue-500 to-blue-700`** (혹은 동등 토큰)
- 내용: **실명의 첫 글자(이니셜)** — 한글 1자 (예: 구), 영문은 First-name 첫 1자.
- 폰트: 흰색, bold, 비율은 일반 회원의 사람 아이콘 자리와 동일 크기.

### 2-2. 우측 영역

- 상단: 라벨 «로그인 계정» 아래 **이메일** 표시 (예: `drkoo@snuh.org`). 이메일 자체는 일반 회원과 동일하게 노출.
- 우측 끝: **로그아웃 아이콘** (동작은 기존 [로그아웃 팝업 정책]과 동일).

### 2-3. 상단 앱바 «의사» 뱃지

- 위치: 「마이페이지」 텍스트 우측, 작은 캡슐.
- 톤: 횡단 정책 2-2에서 결정된 톤(권장 `expert` 보라).
- 라벨: 단순 「의사」 (마이페이지 헤더는 짧게).
- 본문 작성자 표기에 쓰는 «인증 의사» 뱃지와 시각적으로 일관.

## 3. M02 — 닉네임 → **실명 모드로 교체** (변경의 핵심)

기존 닉네임 카드(필수 입력, 2~10자, 「저장하기」)는 **전체 제거**되고 아래 «실명 카드»로 교체됩니다.

### 3-1. 카드 구성

```
┌─ 실명 ─────────────────────  🔒 인증 정보 ─┐
│  ┌─────────────────────────────────────────┐ │
│  │  구자호 교수                              │ │  ← 읽기 전용 입력란
│  └─────────────────────────────────────────┘ │
│                                               │
│  소속 병원                서울대학교병원        │
│  전문 분야                정형외과 · 척추외과    │
│  인증 상태                인증 완료             │
│                                               │
│  ┌─────────────────────────────────────────┐ │
│  │           의사 프로필 수정                 │ │  ← CTA
│  └─────────────────────────────────────────┘ │
└───────────────────────────────────────────────┘
```

### 3-2. 실명 입력란

- **읽기 전용** (`disabled` + 시각적 잠금).
- 우측 라벨: 작은 글씨 「인증 정보」 + **자물쇠 아이콘**.
- 값: 서버 응답 `realName`.
- 변경 시도(키 입력/클릭) → 토스트 «인증 의사 회원은 실명으로 활동합니다» 노출.

### 3-3. 정보 행 (소속·전문·상태)

- 좌: 라벨 (회색 12px), 우: 값 (검정 14px) — 이미지 2의 표 톤 그대로.
- **소속 병원:** `affiliation.hospital`
- **전문 분야:** `affiliation.specialties.join(' · ')` (최대 3개, 초과 시 «…»)
- **인증 상태:** 「인증 완료」 + 작은 체크 아이콘 (파랑 톤).

### 3-4. CTA — 「의사 프로필 수정」

- 클릭 시 **`DoctorProfileModal`** 또는 **별도 «의사 프로필 편집 화면»**으로 진입.
- 결정 필요(횡단 정책 5-6): 편집 가능 범위.
  - 권장 편집 가능: 자기소개·진료 분야 키워드·논문/경력 추가·진료 시간·태그.
  - 권장 편집 불가: 실명·면허·소속(이는 «재인증» 플로우로 분리).

### 3-5. 닉네임 영역 — 완전 제거

- 기존 입력란/안내문(「최소 2자, 최대 10자」)/「저장하기」 버튼: **렌더링하지 않음**.
- SNS 통합 노티스 블록(M02 하단)은 그대로 노출.

### 3-6. F-MY-111 시나리오 — 실명 고정 / 닉네임 비활성

- **선조건:** `verificationStatus === 'verified'`로 마이페이지 진입.
- **정상 흐름:**
  1. M02 자리에 «실명 카드»가 노출됨 (닉네임 카드는 미노출).
  2. 실명 입력란은 잠겨 있음.
  3. 의사 프로필 수정 버튼 활성.
- **예외:**
  - 실명 입력란을 강제로 활성화하려는 클라 우회 시도 → 서버는 변경 요청을 403으로 거절.
  - 인증 만료 감지 시 → 1번 항목으로 돌아가 일반 회원 모드로 다시 그림.
- **완료 기준:** 사용자에게 닉네임 변경 UI가 일체 노출되지 않음.

## 4. M03 — 내 활동 (부분 변경)

### 4-1. 작성자 표기 자동 갱신

- 게시글/댓글/후기 카드의 작성자 라인이 **현재 인증 상태 기준으로 재계산** (횡단 정책 3-1).
- 본인 카드 안의 «작성자 미리보기»가 있다면 실명+뱃지+소속이 보여야 함.

### 4-2. 「후기」 탭 — 본인 후기 차단 (정책 결정 필요)

- 횡단 정책 5-1: «본인 의사 프로필에 본인이 작성한 후기»는 **차단 권장**.
- 본인 의사 프로필을 명의 찾기에서 열어도 「후기 작성」 버튼이 비활성화되며, 시도 시 403 + 토스트 「본인 의사 후기는 작성할 수 없습니다」 노출.

### 4-3. 「저장」 탭

- 변경 없음. (저장된 의료진 = 즐겨찾기, 인증 상태와 무관)

### 4-4. F-MY-112 시나리오 — 의사 프로필 수정 진입

- **선조건:** 인증 의사 모드.
- **정상 흐름:**
  1. M02 카드의 「의사 프로필 수정」 탭.
  2. `DoctorProfileModal`(또는 편집 화면)로 진입.
  3. 편집 허용 필드만 활성. 인증 항목은 잠금.
- **예외:**
  - 편집 후 저장: 명의 찾기·홈·커뮤니티의 모든 표기가 다음 화면 진입 시 갱신됨.
  - 잠금 필드 변경 시도: 토스트 「이 정보는 재인증을 통해 변경할 수 있습니다」.
- **완료 기준:** 변경 사항이 «내가 등장하는 모든 화면»에서 일관되게 보임.

## 5. M04 / M05 — 고객지원 · 탈퇴 (부분 변경)

### 5-1. M04 고객지원

- 「공지·이용약관·개인정보·의견 보내기」 항목은 **그대로**.
- 횡단 정책 5-5에 따라 인증 의사는 **마이페이지에 인증 신청 진입점을 두지 않음** (이미 인증 완료이므로 의미 없음). 단, **재인증** 진입은 별도 검토 필요.

### 5-2. M05 탈퇴 — 추가 안내

탈퇴 시 «인증 의사»에게는 기존 안내(2-a 콘텐츠 삭제 불가, 2-b 24시간 재가입 불가)에 더해 다음을 노출합니다.

- **2-c. 인증 정보 처리 안내 (체크 필수):**
  - 「면허·소속 등 인증 검증에 사용된 정보는 관련 법령에 따라 [N]개월간 보관 후 파기됩니다.」
  - [N]은 횡단 정책 5-7 결정값. (법무 검토 필요)
- **2-d. 작성물 표기 안내 (체크 필수):**
  - 「탈퇴 후, 작성하신 게시글·댓글·후기의 작성자는 «탈퇴한 회원»으로 표시됩니다.」
  - 이 정책은 횡단 정책 3-1과 충돌 시 본 항목이 우선합니다 (탈퇴는 회원 자체가 사라지는 케이스).

### 5-3. 탈퇴 완료 팝업

- 본문 문구 추가: 「인증 정보는 [N]개월 후 파기됩니다.」 1줄.

### 5-4. F-MY-113 시나리오 — 인증 해제 / 재인증 / 탈퇴 데이터 처리

- **케이스 A. 자발적 인증 해제 (만약 도입 시):**
  - 의사 프로필 측 「인증 해제」 탭 → 확인 팝업 → 닉네임 복원(`previousNickname`) → 일반 회원으로 복귀.
- **케이스 B. 재인증 (만료 후):**
  - 마이페이지 상단 «인증 만료» 배너의 「재인증」 탭 → 의사 인증 신청 플로우 진입.
- **케이스 C. 탈퇴:**
  - 위 5-2의 체크 4종 → 「탈퇴하기」 활성 → 탈퇴 처리.
  - 탈퇴 후 작성물 표기는 「탈퇴한 회원 (인증 의사)」 또는 「탈퇴한 회원」 (정책 결정 필요).

## 7. 접근성 / 카피 / 분석

### 7-1. 접근성

- 실명 입력란은 `aria-readonly="true"`, `aria-label="실명 (변경 불가)"`.
- 자물쇠 아이콘에는 스크린리더 라벨 「인증 정보 잠금」.
- 의사 프로필 수정 버튼은 `role="button"` + 명확한 라벨.

### 7-2. 카피 톤

- 의료광고법 회피: 마이페이지에서는 «최고», «추천», «1위» 등 표현 금지.
- 「의사 프로필 수정」 안내문(있다면): 「프로필 변경은 일반 정보에 한합니다. 면허·소속 변경은 재인증이 필요합니다.」

### 7-3. 분석 이벤트 (요약)

| 이벤트명 | 발생 시점 | 메타 |
|---------|----------|------|
| `mypage_doctor_view` | 인증 의사 마이페이지 노출 | screen=mypage, role=doctor |
| `mypage_doctor_edit_click` | 「의사 프로필 수정」 탭 | screen=mypage |
| `mypage_doctor_nickname_attempt` | 실명/닉네임 변경 시도 | screen=mypage, blocked=true |
| `mypage_doctor_renew_click` | 만료 배너의 재인증 탭 | screen=mypage |
