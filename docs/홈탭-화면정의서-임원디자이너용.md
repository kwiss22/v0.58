> 버전 1.1 · 2026.02.26 · 기획·디자인·의사결정 논의용 · 기술 용어 없음

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 이름 | 홈 화면 (첫 번째 탭) |
| 진입 방법 | 앱을 처음 실행하거나, 하단 탭 메뉴에서 "홈" 터치 |
| 대상 사용자 | 비회원 · 회원 공통 (일부 기능만 구분) |
| 화면의 목적 | AI 챗봇으로 자연스럽게 유도 / 질환별 명의 탐색 / 주변 명의 병원 찾기 / 건강 정보 읽기 |
| 화면 형태 | 상단 고정 헤더 + 위아래 스크롤 콘텐츠 + 하단 탭 메뉴 |
| 기준 화면 | 모바일/PC 웹 반응형 (항상 가운데 정렬) |

| 카드 위치 | 표시 내용 | 터치 시 동작 | 비고 |
|---|---|---|---|
| 왼쪽 — 커뮤니티 추천글 | 글 종류 뱃지 · 제목(최대 2줄) · 내용 미리보기 · 좋아요·댓글 수 · 날짜 | 해당 게시글 팝업 열림 | 화면 진입 시 랜덤으로 글 1개 선택. **게시글이 없으면 카드 자체가 사라짐 → 정책 결정 필요 (EX-01)** |
| 오른쪽 — 내 주변 명의 병원 | "명의 인증 병원" 뱃지 · 암/중증/희귀질환 태그 · "위치 기반" 문구 | 주변 병원 팝업 열림 | 회원/비회원 구분 없이 동일하게 보임 |

## 3. 팝업 화면 설명

## 5. 정책 결정이 필요한 사항

> ⚠️ 아래 항목은 기획·경영 의사결정이 필요하며, 결정 전까지 개발이 보류됩니다.

---

### 🔴 EX-01 (높음) — 서비스 오픈 초기, 커뮤니티 글이 없을 때

**상황:**
홈 화면의 왼쪽 "커뮤니티 추천글" 카드는 게시글이 없으면 사라집니다.
서비스 오픈 직후에는 반드시 이 상황이 발생합니다.

**결정 요청:**
아래 셋 중 하나를 선택해 주세요.
1. 빈 카드를 보여줍니다 (예: "첫 번째 글을 작성해보세요")
2. 오른쪽 "명의 병원" 카드를 화면 전체 너비로 넓힙니다
3. 다른 콘텐츠로 채웁니다 (어떤 콘텐츠?)

---

### 🔴 EX-02 (높음) — 특정 질환 탭에 등록된 의사가 없을 때

**상황:**
예: "자궁암" 탭 선택 시 해당 의사가 0명이면 해당 영역이 빈 화면으로 표시됩니다.

**결정 요청:**
"현재 해당 질환의 명의 정보를 준비 중입니다" 같은 안내 문구를 넣을지,
다른 방식으로 처리할지 결정해 주세요.

---

### 🔴 EX-03 (높음) — 위치 기반 병원 검색 정책

**상황:**
홈 화면의 "내 주변 명의 병원" 카드에 "위치 기반"이라는 문구가 있지만,
현재는 실제 위치를 가져오지 않고 서울 중심부 좌표가 고정으로 표시됩니다.

**결정 요청:**
아래 둘 중 하나를 선택해 주세요.
1. 사용자에게 위치 권한을 요청합니다 (브라우저 팝업으로 허용/거부 선택)
2. 수동으로 지역을 검색하는 방식으로 바꿉니다

---

### 🟡 EX-04 (중간) — 인터넷이 끊겼을 때

**상황:**
오프라인 상태에서 지도가 회색 빈 박스로 표시되고, 건강 기사도 열리지 않습니다.
사용자 안내가 전혀 없습니다.

**결정 요청:**
"인터넷 연결을 확인해주세요" 같은 안내를 어떤 형태로 보여줄지 결정해 주세요.
(팝업 알림 / 화면 내 안내 문구 / 기타)

---

### 🟡 EX-08 (중간) — 건강 기사 팝업 차단 가능성

**상황:**
건강 기사를 앱 팝업 안에서 보여주려 하는데,
일부 외부 뉴스 사이트는 이를 기술적으로 차단합니다.
이 경우 팝업 안이 빈 화면이 됩니다.

**결정 요청:**
아래 둘 중 하나를 선택해 주세요.
1. 팝업 안에서 시도하고, 실패 시 외부 브라우저로 전환합니다
2. 처음부터 외부 브라우저(새 탭)로 열어줍니다

## 6. 현재 임시 데이터 현황

> 아래 항목은 현재 실제 데이터가 아닌 가상의 샘플 데이터로 표시됩니다.
> 서버 연동 전까지 프로토타입용으로 사용됩니다.

| 항목 | 현재 상태 | 실제 서비스 시 필요한 것 |
|---|---|---|
| 의사 목록 (명의 탐색) | 가상 인물 7명 (임의 작성) | 실제 의사 DB 연동 및 검증 필요 |
| 주변 병원 목록 | 가상 병원 7개 (임의 작성) | 위치 기반 병원 데이터 연동 필요 |
| 커뮤니티 추천글 | 샘플 게시글 여러 개 (임의 작성) | 실제 커뮤니티 게시글 데이터 연동 필요 |
| 댓글 | 샘플 댓글 3개 (임의 작성) | 실제 댓글 데이터 연동 필요 |
| 건강 정보 기사 | 12개 기사 목록 (임의 선정) | 실제 의학 콘텐츠 수급 및 라이선스 확인 필요 |
| 의사 프로필 사진 | 아이콘 대체 (사진 없음) | 실제 의사 동의 후 사진 등록 필요 |
| 건강 기사 썸네일 | 회색 빈 박스 | 기사별 대표 이미지 연동 필요 |

> ⚠️ 의사 정보는 실명이 노출되므로 반드시 사전 동의 및 법적 검토가 필요합니다.
