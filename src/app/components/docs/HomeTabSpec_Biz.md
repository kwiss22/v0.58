# Aiga — 홈 화면 정의서

> **버전** v0.6 · **작성일** 2026.03.27 · 임원·디자이너용  
> **성격:** UI/UX·정보 구조·인터랙션 중심. 옆 **프로토타입(데모) 화면**은 레이아웃·동작을 이해하기 위한 참고용이며, **화면에 보이는 수치·목록·명의·게시글은 더미**입니다. 실제 서비스의 데이터·랭킹·API와 같다고 보지 마세요.

---

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 이름 | 홈 화면 (첫 번째 탭) |
| 진입 방법 | 웹을 처음 열거나, 하단 탭 메뉴에서 "홈" 터치 |
| 대상 사용자 | 비회원 · 회원 공통 (일부 기능만 구분) |
| 화면의 목적 | AI 챗봇 유도 / 질환별 인기 명의 탐색 / 커뮤니티 추천글 열람·공감 / 건강 정보(외부 기사 링크) |
| 화면 형태 | 상단 헤더 + 스크롤 콘텐츠 + 하단 탭. **통합 검색**은 각 탭 헤더 줄과 별도로, **반응형 웹**에서 **메인 뷰(모바일 우선 폭) 우상단에 고정**된 돋보기 버튼에서 열림(스크롤해도 같은 위치). 네이티브 앱 단일 프레임이 아님 |
| 기준 화면 | 모바일 우선 (스마트폰 세로 화면 기준) |

### 구역 4 — 커뮤니티 추천글 (가로 스크롤)

| 요소 | 설명 | 비고 |
|---|---|---|
| 제목·더보기 | "커뮤니티 추천글" + "더보기 →" | 더보기는 커뮤니티 탭 이동 |
| 카드 수 | 최대 **5장** 표시 | 최근 **3개월** 이내 작성글 중 인기 상위 **20~30**개에서 매번 **랜덤 5개** 샘플링·표시 |
| 스크롤 | 가로 스크롤. 터치 조작에 최적화, 상위 세로 스크롤과 터치 충돌 방지. **iOS Safari** 등 가로 스크롤 이슈 고려 | — |
| 카드 내용 | 프로필 사진 · 닉네임 · 날짜(**경과 시간 우선**: N분/시간/일 전, 아니면 `YYYY.MM.DD`) · **제목**(최대 **2줄** 말줄임) · **본문 첫 50자** 미리보기 · 공감 수 · 댓글 수 | **v1.1** 조회수는 **화면에 표시하지 않음**. 백엔드에서만 수집 |
| 인증 뱃지 | 인증된 작성자에게 **체크 배지** 표시 | — |
| 카드 터치 | 커뮤니티 게시글 **상세 팝업** 열림. 조회수 카운팅 타이머 시작 | 조회수는 화면 노출 없이 **백엔드** 집계 |
| 조회수 +1 조건 | 상세 팝업이 **3초 이상** 연속 열려 있을 때 **한 번** 카운팅. 또한 동일 사용자가 해당 글을 **24시간 이내** 이미 읽은 경우 **+1 안 함** | 실수 클릭·남발 방지 및 인기 점수·분석 신뢰도 |

**비회원 / 회원 차이 (구역 4)**

| 구분 | 비회원 | 회원 |
|---|---|---|
| 추천 카드·가로 스크롤 | 열람 | 동일 |
| 카드 → 상세 | 열람 한도 정책이 있으면 차감·소진 시 안내 | **열람 한도 없음**. 조회수 +1 규칙(3초·24h)은 동일 |
| 상세: 본문·이미지 | 열람 | 열람 |
| 상세: 게시글 공감 | 로그인 유도 | 토글·재탭 취소, 홈 카드 수치와 맞출 것 |
| 상세: 댓글·답글 | 입력 불가 | 작성·전송·답글 |
| 상세: 댓글 공감 | 불가 | 토글 |
| ⋮ 메뉴 | 공유만 | 공유 + 본인 글 수정·삭제 + 타인 글·댓글 신고 |
| 병원·의사 카드 | 정책대로 | 동일 + 프로필 등 연동 |
| 더보기 → 커뮤니티 | 탭 이동 | 이동 후 전체 피드·필터·글쓰기 등 |

**회원만 해당 — 구역 4 맥락에서 할 수 있는 일**

- 홈에는 추천 5장만 노출되지만, 회원은 **카드 탭 → 상세**에서 제한 없이 본문·댓글까지 읽고 **공감·댓글·답글·댓글 공감**까지 수행.
- **신고·수정·삭제**는 상세 ⋮ 메뉴(및 댓글 UI)에서 회원만.
- **더보기**로 커뮤니티 탭 진입 시 검색·카테고리·내 글 등 홈 밖 **전체 커뮤니티 회원 기능** 사용.
- (후속) 게시글 0개일 때 안내의 글쓰기 버튼은 회원 **즉시 글쓰기** 플로 연결 목표.

**게시글 0개(빈 목록):** 섹션 **미노출이 아니라** "첫 글을 작성해보세요!" 등 **안내 카드 + 글쓰기 유도 버튼** 표시. *현재 앱엔 빈 배열 분기 미구현.*

**인기 점수:** `Likes × 10 + Comments × 3 + Views × 1` → 최근 3개월 필터 → 상위 20~30 풀 → **랜덤 5개** 표시.

**조회수 정책:** 카드에는 미표시. 3초·24시간 규칙은 백엔드 수집용. 추후 마이페이지 "내가 쓴 글"에서 작성자에게만 노출 가능.

## 3. 모달·연동 요약

### 의사 프로필

홈의 인기 명의 카드에서 진입. 상세는 **공통 컴포넌트 정의서** 참조. 비회원은 북마크·리뷰 작성 시 로그인 유도.

### 커뮤니티 게시글 (홈)

- 홈·통합검색에서 열리는 **게시글 상세 모달**은 커뮤니티 탭 피드 상세와 **같은 UX 패턴**(본문·공감·댓글·더보기)을 목표로 함.  
- 회원: 댓글, **공감 토글**. 비회원: 제한·로그인 유도. (프로토타입에서 구현 모듈명은 개발 참고용.)

### 건강 기사

**모달 없음.** 외부 링크로 바로 이동.

### 통합 검색

홈에서도 우상단 돋보기로 동일 모달 사용. 검색 결과의 커뮤니티 글을 열면 위와 같은 **CommunityPostModal**이 뜹니다.  
「커뮤니티에서 더 보기」는 **커뮤니티 탭으로 이동**하는 흐름. 검색어를 커뮤니티 필터에 넘길지는 **제품 정책**(프로토타입은 미연동일 수 있음).
